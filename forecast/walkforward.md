## Method

- **Origins.** 11 origins 1975-01, 1979-01, ..., 2015-01; the last window ends 2018-12; none overlaps the 2021-01..2024-12 demo window. The plan said '1975-2017'. 11 non-overlapping 48-month windows span 528 months, but 1975-01..2017-12 holds 516, so that range cannot contain 11 windows with both endpoints. Starting at 1975-01 and stepping 48 months is the declared choice.
- **No look-ahead.** Fits: every fit uses observations dated up to t0 - 1 (bt.fit_ar1 calls macrolib.fit_ou(until = t0 - 1), which includes `until`); the AO sigma_delta uses the same sample. Pre-origin caps use only windows that start >= 1960-01 and ended <= t0 - 1. Climatology uses only windows (from 1914-01) that ended <= t0 - 1. evaluate_origin raises if a fit, a climatology window or a cap window reaches t0 or later.
- **Release timing.** As in backtest.py, the forecast at t0 uses CPI for t0 - 1, which BLS publishes in the middle of month t0; the release lag is not otherwise modelled, and the values are FRED's current ones, not first-release vintages.
- **AR(1).** exactly the primary specification of forecast/backtest.py: OLS y_{t+1} = a + b y_t + e on 1914-01..t0-1, Gaussian innovations with the fitted residual sd (ddof = 2), 48 months from x0 = y_(t0-1).
- **Atkeson-Ohanian random walk (AO).** Atkeson-Ohanian (2001, 'Are Phillips curves useful for forecasting inflation?', Federal Reserve Bank of Minneapolis Quarterly Review 25(1)) use the four-quarter random walk as their benchmark: next year's inflation is forecast to equal last year's. This is its natural path extension: the 48 forecast values start at x_(t0-1) and follow a driftless Gaussian random walk x_{t+1} = x_t + e, e ~ N(0, sigma_delta^2), with sigma_delta the sample sd (ddof = 1) of the monthly changes of the year-on-year series over the same sample as the AR(1) fit. It is AR(1) with a = 0 and b = 1 (simulated by bt.simulate_paths). The path extension, not the point-forecast rule, is this analysis's choice.
- **climatology.** as forecast/backtest.py: realised scores of every 48-month window that ended <= t0 - 1, from 1914-01.
- **Simulation.** 10000 paths, 48 months, base seed 20261025. numpy SeedSequence([seed, stream, year*12+month]) via bt.origin_rng; stream 0 AR(1) simulation and stream 1 PIT draws (ar1, clim) as in backtest.py, so AR(1) and climatology rows reproduce backtest.py's at the same seed and origin; stream 3 AO simulation, stream 4 AO PIT draws. simulated percent -> floor(y * 1e4) contract units, then the exact integer recursions and scores of eqs. (2)-(6) (bt.forecast_stats, bt.scores); contract statistics start afresh at the first forecast month.
- **Cap policy B.** pre-origin p90 caps (honest): 90th percentile of the exact integer statistic over eligible 48-month windows; eligible windows: start >= 1960-01 (declared post-1960 rule) and end <= t0 - 1; rounding: round half up to an integer in contract units (declared here: the repo has no integer rounding rule).
- **Cap policy A.** fixed caps 8 pp / 80 pp-months (retrospective: chosen after seeing 2021–24).
- **V0.** mean of the model's score distribution, in [0, 1]; a forecast, not a price.
- **CRPS.** empirical-distribution CRPS of the score (bt.crps_ensemble, pair term 1/(2n^2)).
- **Randomised PIT.** randomised PIT u = F(y-) + v (F(y) - F(y-)), seeded v (bt.randomized_pit).
- **Literal tail exceedance.** literal tail exceedance: the realised score is above the model's 90% quantile (inverted-CDF quantile of the model's integer scores). With probability mass at the cap this can never fire when that quantile is the cap, so it undercounts for a model that puts more than 10% of its mass at the cap.
- **Randomised upper-tail count.** randomised tail exceedance u > 0.9; probability exactly 10% under calibration, including mass points. It is the count compared with Binomial(11, 0.1).
- **Randomised lower-tail count.** randomised lower-tail count u < 0.1, also exactly 10% under calibration; a forecast that runs high puts the realised score in its lowest decile too often. Read against the same binomial.
- **Lowest CRPS of three.** per origin, the model with the lowest CRPS of AR(1), AO and climatology; exact ties count for each tied model and are reported.
- **Sign test.** per pair of models, two-sided exact sign test (p = 1/2) on the origins where the CRPS differs; descriptive, 12 comparisons that are not independent.
- **Binomial reading.** exceedance counts are read against Binomial(n = 11, p = 0.1), assuming independent origins.
